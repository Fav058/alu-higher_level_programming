The ``5-text_indentation`` module
===================================

    >>> text_indentation = __import__('5-text_indentation').text_indentation

Basic usage with a period:

    >>> text_indentation("Hello.")
    Hello.
    <BLANKLINE>

Question mark:

    >>> text_indentation("How are you?")
    How are you?
    <BLANKLINE>

Colon:

    >>> text_indentation("Note:")
    Note:
    <BLANKLINE>

Multiple sentences:

    >>> text_indentation("Hi. Bye?")
    Hi.
    <BLANKLINE>
    Bye?
    <BLANKLINE>

Empty string prints nothing:

    >>> text_indentation("")

Not a string:

    >>> text_indentation(88)
    Traceback (most recent call last):
    TypeError: text must be a string
